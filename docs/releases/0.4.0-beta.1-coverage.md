## Supporting changes

These support the features above and do not need separate consumer-facing bullets:

- Frontend/backend contract additions and matching contract fingerprints: source ranking, browser plans and stream metadata.
- CSP CDN allowlists in `public/_headers` and `vercel.json`: required for the documented browser transfer paths.
- Backend browser-plan route, ownership checks, short-lived source grants and in-memory cleanup: support browser downloads; the post explains tab/cache lifetime without exposing implementation details.
- Shared worker launcher, Docker resolver copy and pinned networking dependencies: support metadata reuse and source networking fixes.
- Tests, verification scripts, benchmarks and source-specific evidence files: validation, not additional product features.
- Responsive banner exports and saved image-generation prompt: artwork provenance and delivery assets.

## Release boundary

This is a two-repository change. The frontend post is in `Convert`; audio selection, encoder defaults, source-networking improvements, reusable metadata workers and browser-plan support are in `ClyvoraAPI`. Publishing the frontend alone does not install those backend improvements.

No commit, push or deployment was performed during this audit. Source availability, regions and first checks can still vary; the notes make no instant-download or universal-compatibility claim.
